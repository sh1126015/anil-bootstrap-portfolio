# Anil Shrestha — Bootstrap Portfolio

A responsive Bootstrap 5 website created for CSCE 3420. It includes personal text, the author's name, a local SVG image, responsive navigation, and custom styling.

## Run locally

Open `index.html` in a browser.

## Deploy with AWS Amplify

1. Push this folder to a GitHub repository.
2. In AWS Amplify, choose **Create new app → Host web app**.
3. Choose GitHub, authorize it, and select the repository and branch.
4. Keep the default build settings and choose **Save and deploy**.
5. Submit the generated `amplifyapp.com` URL in Canvas.
